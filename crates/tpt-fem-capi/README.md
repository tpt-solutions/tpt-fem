# tpt-fem-capi

C ABI for the `tpt-fem` core, so C, C++, Julia, MATLAB, R, .NET and Java (via
FFI) can call it. Mirrors the Python bindings: mesh handling plus
`tpt_solve_poisson`, `tpt_solve_elasticity`, `tpt_solve_modal` and
`tpt_topopt_cantilever`. Dev-only (`publish = false`), excluded from the Cargo
workspace like `tpt-fem-py` and `tpt-fem-wasm`.

```sh
cargo build --release     # -> target/release/{tpt_fem_capi.dll|libtpt_fem_capi.so|.dylib, .a/.lib}
cargo test                # FFI tests, called the way C would
```

The header [`include/tpt_fem.h`](include/tpt_fem.h) is generated by cbindgen
during `cargo build` and committed; CI fails if it drifts.

```c
#include "tpt_fem.h"

TptMesh *mesh; TptField *u;
tpt_mesh_box(lo, hi, n, &mesh);
if (tpt_solve_poisson(mesh, 1.0, 2, 0.0, NULL, NULL, bcs, n_bcs, &u) != TPT_OK)
    fprintf(stderr, "%s\n", tpt_last_error_message());
double *values = (double *)tpt_field_data(u);   /* tpt_field_len(u) doubles */
tpt_field_free(u); tpt_mesh_free(mesh);
```

A complete program is in [`examples/poisson.c`](examples/poisson.c):

```sh
gcc examples/poisson.c -Iinclude -Ltarget/release -ltpt_fem_capi -o poisson
```

## Conventions

- **Handles** (`TptMesh`, `TptField`, `TptModal`, `TptTopopt`) are opaque and
  returned through `out` pointers; free each with its `tpt_*_free` (NULL is a no-op).
- **Status codes**: every fallible function returns `TPT_OK` (0) or
  `TPT_ERR_INVALID_ARG` / `TPT_ERR_SOLVE` / `TPT_ERR_IO` / `TPT_ERR_PANIC`.
  `tpt_last_error_message()` describes the last failure on the calling thread.
- **No panics cross the boundary**; they become `TPT_ERR_PANIC`.
- **Arrays** are `(pointer, length)`. Node-id queries are snprintf-style: call
  with `cap = 0` to get the count, then again with a buffer.
  Pointers returned by `tpt_field_data` / `tpt_modal_shape` /
  `tpt_topopt_densities` stay valid until the owning handle is freed.
- **Callbacks**: the Poisson source may be a C function
  `double f(double x, double y, double z, void *user)`; it runs on the calling thread.
- Vector DOF numbering is `node * dim + component`.
